## HTML snapshots

The original `README.html` and `docs/checklist_new_features.html` are snapshots
of their same-named source Markdown documents. Their English counterparts are
`README.en.html` and `docs.en/checklist_new_features.html`. Do not maintain
an independent feature list in HTML.

Regenerate only the English snapshots from the repository root with
PowerShell 7:

```powershell
Set-Content -LiteralPath README.en.html -Encoding utf8 -Value ('<meta charset="utf-8">' + "`n" + (ConvertFrom-Markdown -Path README.en.md).Html.TrimEnd())
Set-Content -LiteralPath docs.en\checklist_new_features.html -Encoding utf8 -Value ('<meta charset="utf-8">' + "`n" + (ConvertFrom-Markdown -Path docs.en\checklist_new_features.md).Html.TrimEnd())
```

The renderer is built into PowerShell; no project or system package install is
required. Review the generated links, code blocks and tables with the Markdown
change. The commands above do not modify the original Chinese files.

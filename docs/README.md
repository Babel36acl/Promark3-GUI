## HTML snapshots

`README.html` and `docs/checklist_new_features.html` are rendered from their
same-named Markdown sources. Do not maintain an independent feature list in
HTML. Regenerate from the repository root with PowerShell 7:

```powershell
Set-Content -LiteralPath README.html -Encoding utf8 -Value ('<meta charset="utf-8">' + "`n" + (ConvertFrom-Markdown -Path README.md).Html.TrimEnd())
Set-Content -LiteralPath docs\checklist_new_features.html -Encoding utf8 -Value ('<meta charset="utf-8">' + "`n" + (ConvertFrom-Markdown -Path docs\checklist_new_features.md).Html.TrimEnd())
```

The renderer is built into PowerShell; no project or system package install is
required. Review the generated links, code blocks and tables with the Markdown
change.
